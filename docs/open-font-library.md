# Studio open font library

The library contains 21 optional OFL-1.1 font families. Six cover Chinese (Noto Sans SC, Noto Serif SC, Ma Shan Zheng, ZCOOL XiaoWei, ZCOOL KuaiLe and ZCOOL QingKe HuangYou); fifteen cover Latin interface, serif and monospace typography. Latin stacks include a Chinese fallback. Existing drafts and the HappyHands website shell keep their selected fonts.

Source packages are distributed by [Fontsource](https://fontsource.org/docs/getting-started/install). Each family's name, package/version, SHA-512 archive integrity, source and license URL are pinned in `packages/font-library/catalog.json`. Font binaries are unchanged. Each public font directory retains the package's complete original `LICENSE.txt`, including copyright notices. The [OFL](https://openfontlicense.org/) permits commercial use subject to its terms; it does not grant rights to sell the fonts by themselves or remove their license notices.

Run `node scripts/vendor-open-fonts.mjs` from the repository root to reproduce `public/fonts/` using the pinned versions. The script verifies the package license and archive integrity, copies only WOFF2 assets referenced by the selected face CSS and preserves unicode ranges. Variable families use normal-style variable faces; static families use 400 and 700 where available. Unsupported weights/styles use browser synthesis. The downloaded source packages remain in ignored `test-results/font-downloads/`.

Font CSS loads only when a known library family is the primary family of a selected project stack; its library fallbacks load too. Platform-first stacks do not activate dormant library fallbacks, preserving their existing behavior. The browser fetches character subsets on demand. Loading is independent of whether the typography controls are mounted, so a saved/imported font also works after reload, on other preview scenes and in comparison mode. A failed request leaves fallbacks visible and exposes retry. Arbitrary custom fonts are not downloaded or requested from third parties.

Project previews load `preview.css`, which registers private `HH Preview …` font-family aliases. Only preview CSS variables and specimen styles refer to those aliases. The shell's Noto fallback cannot accidentally pick up a selected project font. Saved and exported theme values retain the public family names.

The font control provides source/license links and a copyable `index.css` stylesheet import for the selected family and Chinese fallback. Exported theme tokens continue to contain font-family values; they do not bundle font binaries. Applications using exported themes or connected external previews must load those public stylesheets too, or self-host the assets with their licenses. The provided imports use the current website origin.
