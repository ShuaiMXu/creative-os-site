# 官网首页与二级页面统一优化

## 本轮范围

首页 `/apps/portal/`、HappyHands `/systems/happyhands/`、Quartz `/systems/quartz/`、主题工作室 `/apps/studio/`。

首页用于介绍和选择；设计系统详情用于规范、组件示例及接入说明；主题工作室用于编辑、预览和导出。官网仍通过接入指引连接本地工作台。

## 已完成

- HappyHands 成为首页设计系统区域的首个、主要入口。Quartz 改为次级外部系统介绍，保留本站详情页。其他案例与预设探索折叠保留。
- 移除首页重复的 Quartz 安装提示词与兼容性说明，详情页仍保留。统一“主题工作室 / Theme Studio”称呼；修正“官方组件预览”等不准确文案。
- 首页和三个二级页面共享导航数据、外观控件和偏好读取规则；三个 React 页面复用 SiteHeader。主题工作室的项目选择保留在独立工具栏中。
- 未保存偏好时跟随系统外观，页面载入不再写入浅色偏好。手动选择跨页面保留，其他标签页的偏好变化同步响应。
- 主题工作室补充中英文界面文案，包括主要操作、设计规范、预览场景、状态示例、导入导出和审核面板。切换语言不重载页面，不清空正在编辑的草稿。项目名称、输入内容、变量名和外部页面内容保留原文。
- 工作室原 `/apps/designer/` 链接改为官网的本地工作台接入指引；不把旧官网演示页当作真实本地工作台。
- 设计系统目录在桌面持续显示，在平板和手机折叠；导航和目录可使用键盘。
- 清除旧主题 hook、闲置目录横排筛选代码和旧工作室页头样式。

## 验证

- `npm run typecheck`、`npm run build`。
- `npm run test:studio`：17 项通过；原路由边界回归通过。
- `test:studio:browser`：编辑、撤销重做、保存、导入导出、预览连接、审批与手机布局通过。
- `test:studio:brand`：品牌默认值、规范检查、组件状态、外观与预览模式分离通过。
- 新增 `test:site:browser`：首页 → HappyHands → 首页 → Quartz → 主题工作室 → 首页 → 接入指引；1280 / 768 / 390px，浅色 / 深色；语言继承、目录展开、弹窗 Enter / Escape 与焦点返回、语言切换保留编辑、英文面板、整页溢出与脚本错误。
- 另外逐一查看工作室七个英文预览场景，未发现中文界面文案残留。

本地预览使用 `http://127.0.0.1:4192`。内置浏览器自动化连接不可用，因此使用独立 Chrome 验证同一站点。截图保存在忽略目录 `test-results/site-flow/`。以上为本地验证，不代表远端 CI 或部署结果。

## 保留边界

- Quartz 仍是本站整理的资料与接入页，不是已经安装的 Quartz 组件运行环境。
- HappyHands 官网与本地工作台跨仓库组件统一不在本轮范围内。
- 外部审阅案例、上游来源和本地启动文档仍按其用途链接到原始仓库。

## Quartz 详情页结构补充

根据首页与详情页脱节的反馈，Quartz 改为官网详情布局：增加“设计系统 / Quartz”返回路径，以 Quartz 为主标题，复用首页卡片介绍，概况与主介绍并排。目录移到介绍下方，手机保持折叠。首页与 Quartz 共用 `packages/ui/site-layout.css` 的内容宽度、边距及章节间距；页尾提供 HappyHands 关联入口。组件目录仍为资料说明，不声称已经安装交互组件。
