# 设计系统展示补全

本轮沿用 HappyHands 的字体、深浅色、网格、圆角和共享导航，不改变主题变量。入口仍为官网设计系统区、`/systems/happyhands/`、`/systems/quartz/`，以及 `/components/?provider=systems` 的同一份内嵌内容。

## 展示内容

- HappyHands：从 canonical `packages/design-tokens/happyhands.json` 读取全部 58 项变量，展示深浅对照、颜色样本、字体、间距、圆角、阴影和层级。支持分类、搜索、复制 CSS 变量引用及完整双模式 CSS/JSON 下载。数量从来源动态计算。
- 组件状态：保留原有 Button、表单、确认弹窗、任务反馈；补充真实 Select、复选、密度、列表筛选和无结果状态。复用现有 Button/Select；其他演示是原生 HTML，不冒充已发布组件。
- 页面组合：项目列表、偏好设置与任务结果。设置可以修改本地预览页头，保存反馈明确不写入真实项目。示例布局保存在 HappyHands 自己的目录，没有新增通用组件 API。
- Quartz：收录上游注册目录的全部 83 项元数据，其中 7 项为页面模板。提供分类、搜索、站内用途与命令展开、复制和来源链接。只保存 name/title/type，不打包上游组件代码、字体或图片；仍明确是目录而非上游运行示例。新组件需要先检查技术兼容性再安装。
- 首页卡片展示对应覆盖范围；长目录先展示 12 项，可继续浏览或展开全部。保持首页原有设计系统、组件库、设计参考三个层级。

## 来源与维护

Quartz 快照位于 `systems/quartz/catalog.json`，附原始 URL、UTC 检查日期和原始响应 SHA-256。执行 `npm run quartz:sync` 显式更新，运行时和构建时不访问上游；新增条目应人工补充说明后再发布。快照只反映检查时注册项，不能保证包含上游未发布或后续新增内容。HappyHands 变量则直接读取工程自己的完整来源。
