# 首页封面与入口层级

2026-10-23

审阅：静态 SVG 无外部资源、脚本或用户输入插值；无嵌套交互控件；删除已失效的轮播初始化及目录数据导入。回归检查覆盖入口、内嵌内容实际加载、双列断点和重复目录。此前已进行 390/768/1280、中英文与深浅色视觉检查。
