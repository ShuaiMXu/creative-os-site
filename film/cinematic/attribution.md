# Provenance

Original composition, authored Northstar fixture and film copy: HappyHands project, 2026-10-24.

Adapted motion grammar and layout-level zoom math from [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft): CardFlipReveal.tsx and PageCam.tsx. The adapted implementation retains the 18-frame trip to 192°, 8-frame quintic return to 180°, backface handling and angle-linked sheen. Source library code is Apache-2.0; the complete license is supplied alongside this file. The original global Skill files were not modified.

SpotlightHeroCard.tsx and its Gallery preview informed single-subject framing and high-resolution capture strategy. This cut does not reproduce its complete spotlight/lift/perimeter-beam/reseat sequence. Do not describe it as an exact SpotlightHeroCard reproduction. Gallery previews were used for analysis, not embedded in the film.
